What is this project?

A small social app where you can log in, browse posts, open a single post, react/comment, create your own posts, and manage your profile (avatar, banner, bio). You can also follow/unfollow other users.

What I worked on:

Login/registration flow and session management.

News feed page with posts and individual view.

Create, edit, and delete my own posts.

Profile Page:

Edit profile (avatar, banner, bio).

Follow/unfollow other users.

View my posts with simple pagination.

Dark theme and a clean, simple design.

How to use it (quickly)

Open the live website (above).

Register a new user and log in.

Create a post, react or comment, visit profiles, and try following/unfollowing.

What I like most

A uniform dark look and simple post cards.

The profile area is intuitive (edit + follow/unfollow).

Search the feed.

The images I use in the posts are uploaded to the hosting so I can control the size.

Built with simple HTML, CSS, and JavaScript using the Noroff public API.
